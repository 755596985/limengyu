# 情侣小窝 💕

一个轻量级的情侣恋爱记录网站，纯 PHP + SQLite 构建，无框架，开箱即用。

## 功能特性

### 📝 内容发布
- 💬 **甜蜜说说** — 记录日常点滴，支持图片上传、视频嵌入（抖音/微信视频链接）
- 💬 **评论与回复** — 每篇说说支持评论互动，楼中楼回复
- 📷 **我们的相册** — 照片墙展示，点击可放大查看，支持批量上传
- 📍 **去过的地方** — 足迹地图，记录一起走过的地点，附带位置解析
- ✅ **待办清单** — 一起完成的事，支持勾选切换完成状态
- 📑 **自定义页面** — 自由创建和管理页面内容

### 👤 用户系统
- **个人主页** — 独立主页（`user.php?id=xxx`），展示用户信息和发布的说说
- **头像上传** — 支持头像上传与缩略图展示
- **签名设置** — 自定义个人签名
- **密码修改** — 支持修改登录密码

### 🛡️ 后台管理
- **内容管理** — 说说、相册、足迹、待办、自定义页面的增删改
- **评论管理** — 管理所有评论与回复
- **用户管理** — 用户列表、编辑弹窗、头像上传、密码修改、删除用户
- **文件管理** — 已上传文件的管理和浏览
- **敏感词过滤** — 配置和管理屏蔽词库
- **访问统计** — 访客记录与统计
- **一言管理** — 自定义格言/句子展示
- **系统配置** — 基础参数配置（站点名称、一言开关等）

### 🔧 其他
- **登录系统** — 账号密码登录，Session 管理
- **API 接口** — 提供 JSON 数据接口（`api.php`）
- **CSRF 防护** — 内置 CSRF Token 验证
- **一键安装** — 访问 `install.php` 自动初始化数据库

## 技术栈

- PHP 8.0+（原生，无框架）
- SQLite（轻量数据库）
- Neumorphism 风格 UI

## 部署

```bash
# 1. 上传源码到网站根目录
# 2. 访问 install.php 完成安装
# 3. 管理员默认账号：admin / admin123
```
