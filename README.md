# 情侣小窝 💕

一个轻量级的情侣恋爱记录网站，纯 PHP + SQLite 构建，无第三方框架，单文件部署，开箱即用。

## ✨ 功能特性

### 📝 内容发布
- **甜蜜说说** — 发布图文说说，记录日常点滴。支持图片上传、视频嵌入（抖音/微信视频链接）、自定义标签
- **评论互动** — 每篇说说支持评论和楼中楼回复，实时刷新
- **双爱心表态** — ❤️赞同 / 💔心碎，同一条说说只能表态一种，互斥切换，点按取消
- **内容审核** — 后台可管理所有说说与评论

### 📷 相册
- **照片墙** — 缩略图网格展示，点击放大查看，支持批量上传
- **自动归类** — 按拍摄日期自动组织照片
- **图片预览** — 集成 lightbox 效果，左右滑动浏览

### 📍 足迹地图
- **地点记录** — 记录一起走过的每一个地方，附带 IP 地址解析为地理位置
- **时间线** — 按时间排序展示所有足迹，标注地点名称和停留时间

### ✅ 待办清单
- **事项管理** — 添加、勾选完成、删除待办事项
- **完成状态** — 点击切换完成/未完成，已完成的自动置底并标记删除线

### 📑 自定义页面
- **自由创建** — 后台可视化创建独立页面，支持富文本内容
- **独立访问** — 每个页面拥有独立 URL，可做纪念日页面、情书等

### 👤 用户系统
- **注册登录** — 支持新用户注册（用户名+密码），账号密码登录，Session 管理
- **个人主页** — 独立主页（`user.php?id=xxx`），展示用户信息、头像、签名和发布的说说
- **头像上传** — 支持自定义头像上传
- **签名设置** — 自定义个人签名展示在主页
- **密码修改** — 支持修改登录密码（需验证旧密码）

### 🛡️ 后台管理
- **管理员登录** — 独立管理员入口，支持密码登录
- **内容管理** — 说说、相册、足迹、待办、自定义页面的增删改查
- **评论管理** — 统一管理所有评论，支持删除
- **用户管理** — 用户列表、编辑信息、头像上传、密码重置、删除用户
- **文件管理** — 已上传文件的管理和浏览
- **敏感词过滤** — 配置和管理屏蔽词库，自动过滤评论内容
- **访问统计** — 访客 IP 记录、页面访问统计
- **一言管理** — 自定义展示格言/句子（通过 api.php 提供 JSON 接口）
- **系统配置** — 站点名称、一言开关、评论开关等基础参数配置

### 🔧 其他
- **CSRF 防护** — 内置 CSRF Token 验证，保障操作安全
- **权限校验** — 后台操作严格校验管理员身份
- **API 接口** — 提供一言 JSON 数据接口（`api.php`）
- **一键安装** — 访问 `install.php` 自动初始化数据库和默认配置
- **移动端适配** — 响应式设计，手机端友好

## 🛠️ 技术栈

| 技术 | 用途 |
|------|------|
| PHP 8.0+ | 服务端语言，全原生无框架 |
| SQLite | 轻量级数据库，无需额外安装 |
| Neumorphism | 新拟态 UI 设计风格 |
| AJAX | 前端异步交互，提升体验 |

## 📁 目录结构

```
├── index.php          # 首页（说说流）
├── login.php          # 登录页
├── register.php       # 注册页
├── user.php           # 用户主页
├── api.php            # 一言 JSON 接口
├── install.php        # 安装向导
├── like.php           # 点赞/表态 API
├── zip_site.php       # 整站打包
├── admin/
│   └── manage.php     # 后台管理面板
├── include/
│   ├── bootstrap.php  # 核心函数库（数据库、用户、配置等）
│   └── config.php     # 系统配置
├── data/              # SQLite 数据库目录
├── uploads/           # 上传文件目录
└── couple_site/       # 可独立部署的站点文件
```

## 🚀 部署指南

### 方式一：传统部署（Apache/Nginx）

```bash
# 1. 将源码上传到网站根目录
# 2. 确保 PHP 8.0+ 环境，已安装 pdo_sqlite 扩展
# 3. 确保 data/ 和 uploads/ 目录有写入权限
# 4. 访问 http://你的域名/install.php 完成安装
# 5. 管理员默认账号：admin / admin123
# 6. 访问 http://你的域名/login.php 登录
# 7. 访问 http://你的域名/register.php 注册新用户
```

### 方式二：宝塔面板

```
1. 新建网站，PHP 版本选择 8.0+
2. 将源码上传至网站根目录
3. 访问 http://你的域名/install.php 执行安装
4. 安装完成后即可正常使用
```

### 方式三：couple_site 独立目录

```
项目根目录下的 couple_site/ 为独立精简版（不包含后台管理），
可直接部署到任意子目录，适合仅需展示内容的情侣使用。
```

### 环境要求

- **PHP**：8.0 或更高版本
- **扩展**：`pdo_sqlite`、`gd`（图片处理）、`mbstring`、`json`
- **Web 服务器**：Apache（推荐 mod_rewrite）或 Nginx
- **存储**：至少 100MB 可用空间（用于上传图片）

## ⚙️ 配置说明

- 安装后可通过后台「系统配置」修改站点名称、一言开关、评论开关等
- 数据库文件位于 `data/` 目录，定期备份该目录即可
- 上传文件位于 `uploads/` 目录
