# 情侣小窝 💕

一个轻量级的情侣恋爱记录网站，支持说说、相册、足迹地图、待办清单等功能。

## 功能特性

- 💬 **甜蜜说说** — 记录日常点滴，支持图片/视频/音乐附件
- 📷 **我们的相册** — 照片墙展示，点击可放大查看
- 📍 **去过的地方** — 记录一起走过的地点
- ✅ **待办清单** — 一起完成的事，标记完成状态
- 📑 **自定义页面** — 自由创建页面内容
- 👤 **用户系统** — 个人主页、头像上传、签名设置
- 🛡️ **后台管理** — 管理员后台管理所有内容

## 技术栈

- PHP 8.0+（原生，无框架）
- SQLite（轻量数据库）
- Neumorphism 风格 UI

## 部署

1. 上传源码到网站根目录
2. 访问 `install.php` 完成安装
3. 管理员默认账号：`admin` / `admin123`
